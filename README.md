## Задание 1 — Бифуркационная диаграмма

Реализовано логистическое отображение \(x_{n+1} = r \cdot x_n \cdot (1 - x_n)\).

- Построена эволюция \(x\) при фиксированном \(r\).
- Для сетки значений \(r\) сохранены последние \(m\) итераций после прогрева в \(n\) шагов.
- Построена бифуркационная диаграмма (диаграмма Фейгенбаума).

**Библиотеки:** NumPy, Matplotlib.

## Задание 2 — Множество Julia

Исследовано отображение \(z_{n+1} = z_n^2 + c\) для комплексных \(z_0\) и \(c\).

- Реализован итерационный алгоритм с ранним выходом при \(|z| > 2\).
- Построены двухцветные и многоцветные карты (число итераций до расходимости).
- Отдельно визуализировано множество для \(c = 1 - \varphi\) (золотое сечение).
- Сделана анимация для семейства \(c = e^{i\alpha}\), \(\alpha \in [0, 2\pi)\).

**Библиотеки:** NumPy, Matplotlib, FuncAnimation.

## Задание 3 — Модель Шеллинга

Агентная модель сегрегации на сетке \(50 \times 50\) с двумя типами агентов.

- Подсчёт соседей через `np.roll` по 8 направлениям.
- Агенты с долей «своих» соседей ниже порога \(R\) переселяются на случайные свободные клетки.
- Серия расчётов для набора порогов \(R \in \{0, 1/8, \ldots, 1\}\).
- Анимации эволюции сетки и график числа «недовольных» агентов по шагам.

**Библиотеки:** NumPy, Matplotlib, FuncAnimation.

## Задание 4 — Спектрограмма

Работа с сигналом из нескольких гауссовых волновых пакетов разной частоты и сдвига по времени.

- Добавлен четвёртый пакет (частота 4, сдвиг 7 циклов) и показан его вклад в спектр FFT.
- Реализована спектрограмма (оконное преобразование Фурье).
- Замерено время FFT для размеров \(2^{14}\) и \(2^{14} \pm 5\); проанализировано, почему длины, равные степени двойки, считаются быстрее (сложность \(O(N \log N)\), выравнивание по памяти, структура алгоритма).

**Библиотеки:** NumPy FFT, Matplotlib.

## Задание 5 — Численное интегрирование

Интеграл \(\int_0^2 (5x - 0.5 e^x + x^{1.5})\, dx\).

- Аналитическое значение через первообразную.
- Численное интегрирование методом трапеций.
- MPI-версия с `mpi4py`: произвольное число процессов независимо от числа точек дискретизации (`COMM.Split`, неравномерное разбиение интервала, `Reduce`).
- Графики ускорения от числа процессов и ошибки от размера сетки.

**Библиотеки:** NumPy, mpi4py, Matplotlib.

## Задание 6 — Циклический сдвиг изображения

Параллельная обработка изображения: столбцы (или строки) сдвигаются по модулю ширины.

- MPI-реализация с разбиением изображения по столбцам между процессами.
- Число процессов не привязано к ширине картинки.
- Замеры ускорения и потребления памяти (`resource`) в зависимости от числа процессов.
- Анимация последовательных сдвигов.

**Библиотеки:** NumPy, PIL, mpi4py, Matplotlib.

## Задание 7 — Правило 110

Элементарный одномерный клеточный автомат «Правило 110».

- Последовательная реализация: эволюция на решётке, визуализация и анимация.
- Параллельная MPI-версия для произвольного числа процессов и длины поля.
- Эксперименты с разными начальными условиями, в том числе классический пример из Википедии (256 итераций от одной живой клетки).
- Графики числа живых клеток во времени.

**Библиотеки:** NumPy, mpi4py, Matplotlib, FuncAnimation.

## Задание 8 — CuPy и GPU

Сравнение вычислений на CPU (NumPy) и GPU (CuPy).

**Задача 1 — SAXPY** (\(z = ax + y\))

- Описана разница NumPy и CuPy и механизм передачи данных между CPU и GPU (`cupy.asarray`, `cupy.asnumpy`, пул памяти).
- Реализован SAXPY через `cupy.RawKernel` на CUDA.
- Построен график времени вычисления в зависимости от размера массива для обеих реализаций.

**Задача 2 — размытие изображения**

- Размытие через свёртку в частотной области (`rfft2` / `irfft2`).
- Сравнение времени NumPy и CuPy на одном и том же изображении \(100 \times 100\).

**Библиотеки:** NumPy, CuPy, CUDA RawKernel, Matplotlib.

## RL-проект — CartPole, DQN и ускорение

Итоговый ноутбук: RL-проект с последующей оптимизацией наиболее затратных участков кода.

### Собственная среда Gymnasium

- Реализован `CartPoleEnv`, совместимый с `CartPole-v1`: физика маятника, методы `reset` / `step` / `render`, режимы `human` и `rgb_array`.
- Пакет `gymnasium_env_RL` собирается через `setup.py` / `pyproject.toml` и регистрируется в Gymnasium (`register`).

### Обучение DQN

- Q-сеть (полносвязная архитектура 4 → 128 → 128 → 2) на PyTorch.
- Replay Buffer, целевая сеть, ε-жадная стратегия с экспоненциальным затуханием.
- Нормализация наблюдений (`NormalizeObservation`).
- Сохранение весов, графики награды и скользящего среднего, анимация поведения обученного агента.

### Ускорение

| Участок кода | Подход |
|--------------|--------|
| `env.step` | Numba `@njit` для физики среды |
| `train_step` | CuPy + CUDA `RawKernel` для TD-градиента и обновления весов |
| `select_action` | CPU (минимизация копирования между CPU и GPU) |

Отдельно измеряется время работы каждого компонента цепочки обучения.

**Библиотеки:** Gymnasium, PyTorch, NumPy, Numba, CuPy, Matplotlib, imageio.

## Запуск

Ноутбуки рассчитаны на **Google Colab** или локальное окружение с Python 3.10+. Часть заданий использует `mpirun`, GPU и виртуальный дисплей для визуализации.

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

Пакет **CuPy** в `requirements.txt` указан как `cupy-cuda12x` (CUDA 12.x). Если у вас другая версия CUDA, замените строку в файле на подходящий пакет — например, `cupy-cuda11x`.

Для заданий с **MPI** (5–7) на локальной машине дополнительно нужен установленный Open MPI и доступная команда `mpirun`. В Colab:

```bash
mpirun -n <N> --allow-run-as-root --oversubscribe python script.py
```

### 2. RL-проект

В [Accelerated_custom_env.ipynb](Accelerated_custom_env.ipynb) ноутбук генерирует каталог `RL/` с пакетом `gymnasium_env_RL`. После выполнения соответствующих ячеек установите его:

```bash
pip install -e RL/
```

### 3. Запуск ноутбуков

```bash
jupyter notebook
```

Откройте нужный `.ipynb` и выполните ячейки сверху вниз — в ноутбуках генерируются вспомогательные `.py`-скрипты, графики и анимации.
